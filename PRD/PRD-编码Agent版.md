## 0. 使用本文件的规则

- **【待定】项**：标【待定】的需求，先向用户提出具体选项并等待拍板，再实现。拍板结果回写到本文件对应条目。
- **技术栈**：本文件只定义产品行为。框架、模型、存储、登录方式等技术选型，开工前与用户逐项确认。
- **验收**：每条需求以「验收」为完成标准；一条需求的所有验收项都可演示，才算完成。
- **优先级**：每条功能需求标 P0 或 P1。P0 全部验收通过才可进入首轮实验；P1 在 P0 全部完成后再做。
- **【建议，开发时确认】**：标此记号的数值或做法是分析建议，不是用户拍板；实现前向用户确认。
- **品类**：首版支持三类饰品：`项链`、`手链`、`耳饰`。凡涉及品类差异的需求，三类都要覆盖。

## 1. 产品一句话与设计主线

**每件手作都独一无二，风格各不相同——用不同风格的工作室，适配不同的饰品。**

给**不会拍、没条件拍**的手作饰品人：上传一件作品，读懂它的气质，为它匹配一间合适的工作室，得到饰品原样不改、可以直接上架的试戴套图。

**设计主线**：产品体验围绕"为这件作品匹配合它气质的工作室"展开，视具体作品而定：
- 为作品选工作室有两条路径：**复用**（调性相近，选一间已有工作室）、**新建**（风格不同，走气质匹配组建一间）。
- 进入工作室后可以**切换**模特或场景，并选择这次要拍的饰品。风格不同的作品，也可以进一间已有工作室、切换模特或场景后再拍。

复用、新建、切换同样一等，体验上都要顺手。在需求取舍和交互细节上有疑问时，优先选择让这三件事更顺手的方案；其余能力（保真、尺寸、实物图、AI 标识、外层 Agent）都服务于这条主线。

成功指标（首轮实验）：10 位目标用户中 ≥5 位把成片上架使用，且 0 例因饰品失真被投诉或撤下。

## 2. 术语（全文统一使用）

| 术语 | 定义 |
|---|---|
| **总资产** | 用户名下全部素材的库，分四类：场景、模特、饰品、店铺参考。另可查看全部成片。 |
| **店铺参考** | 用户上传的店铺视觉参考图（选填）。只用于辅助理解气质，不参与饰品识别；存入总资产后可在聊气质时直接选用。 |
| **场景** | 即用户口中的"背景"。一组环境图 + 氛围设定（氛围、色调、材质、光线）。可以是室内或室外（如海边）。不绑定模特。 |
| **模特** | 一位数字人，独立资产，可用于任何工作室。来源：按作品气质从平台预置库推荐；用户经 Agent 对话生成；用户上传本人照片生成（**本人模特**，规则见 F-05）。 |
| **饰品** | 用户上传的一件饰品：品类 + 正面/侧面/反面三张实拍 + 系统整理出的**标准三视图** + 尺寸。 |
| **标准三视图** | 系统把三张实拍整理成的正 / 侧 / 反三视图：只做抠图与统一背景，饰品像素不改。 |
| **工作室** | 按作品气质匹配出场景与模特后**组建**的「场景 + 模特」组合。饰品不属于工作室：每次拍摄时选择要拍的饰品，一间工作室可以拍多件饰品。用户可拥有多个工作室。**复用** = 为新饰品选一间已有工作室直接拍摄；**新建** = 走一遍气质匹配，组建新的场景 / 模特组合；**切换** = 在工作室内替换模特或场景。 |
| **成片** | 在某个工作室里拍摄生成的图片；一次拍摄产出一套成片。成片归属该工作室，并记录拍摄时使用的场景（含版本）、模特（含版本）、饰品。 |
| **生成额度** | 每位用户实验期可用的 AI 生成张数，规则见 F-11。 |
| **设定卡** | 气质匹配前展示给用户确认的结构化设定，含**背景**（氛围、色调、材质、光线）与**模特**（气质、穿搭、动作）两部分。 |
| **外层 Agent** | 全局常驻的对话助手，可调用工作流：①创建 / 复用工作室；②针对性调整。 |

关系：`工作室 = 1 场景 + 1 模特`；`成片 ∈ 工作室`，每张成片记录 `场景版本 + 模特版本 + 饰品`；场景、模特各自可被多个工作室引用，被修改后所有引用它的工作室同步使用新版本，已有成片不变；饰品可在任意工作室中拍摄。

## 3. 首版范围

**做**：电脑浏览器网站；中文界面；面向国内平台（淘宝、小红书、抖音、闲鱼）商家；登录后使用；实验期免费，每人有生成额度（F-11）；成片仅下载导出。

**首版之外**（需求出现时，记录到 `## 9. 待定与停车场` 并告知用户）：手机端适配、一键发布到电商平台、收费与计价、英文与跨境、全店风格统一模板。

## 4. 用户流程

```
登录 → 首屏「我的工作室」列表
  ├─ 新作品：上传饰品 → 标准三视图确认（F-02）
  │    ├─ 调性与已有工作室相近 → 复用：选工作室（本次拍摄这件饰品）→ 跳到 B1
  │    └─ 风格不同 → 新建工作室：
  │         A1. 聊作品气质 → 设定卡确认（F-03）
  │         A2. 按气质匹配：生成场景 4 张（F-04）+ 推荐 / 生成模特（F-05）
  │         A3. 组建工作室（F-01）→ 进入 B1
  │    B1. 选构图（F-06）
  │    B2. 拍摄 → 一套成片（F-07）
  │    B3. 反馈 / 调整（F-09、F-10）→ 导出（F-08）
  ├─ 进入已有工作室 → 切换模特/场景，或选另一件饰品 → 再次拍摄（F-01）
  └─ 总资产入口（F-01）

Agent 路径（与页面操作并列，F-10，P1）
  上传饰品（F-02，用户完成）→ 对 Agent 说需求
    ├─ 新建：Agent 执行 A1–A3 → 【用户确认设定卡】→ 匹配 → 【用户确认保存为工作室】→ B1
    └─ 复用：Agent 选定已有工作室、选中这件饰品 → B1
外层 Agent 在以上每个页面常驻（F-10）
```

## 5. 功能需求

| 优先级 | 需求 |
|---|---|
| P0 | F-01 – F-09、F-11 |
| P1 | F-10 外层 Agent |

P0 阶段不依赖全局常驻 Agent 面板：F-03 的气质问答、F-05 的对话生成模特、F-09 的「不像」追问，都在各自页面内以点选或输入完成。

### F-01 首屏、工作室与总资产 · P0
- 登录后首屏为「我的工作室」列表，每项显示其场景、模特，以及在其中拍过的饰品缩略图。
- 组建工作室：新建路径中，F-04 保存的场景 + F-05 选定的模特保存为一间工作室，用户可命名；随后以当前饰品进入拍摄。
- **切换**：工作室内可替换模特或场景；每次拍摄前选择要拍的饰品（总资产中任一件）。切换后，已有成片原样保留为历史，新拍成片与旧成片并列。
- **共享资产修改**：场景或模特被修改（含 Agent 经用户同意写入）后，所有引用它的工作室同步使用修改后的版本；已有成片不变，仍记录拍摄时的版本。修改前提示「将影响 N 间工作室」【建议，开发时确认】。
- **删除**：场景、模特正被任一工作室使用时不能删除，提示「被 N 间工作室使用」，用户先在这些工作室中换掉才能删。饰品、店铺参考可直接删除。删除任何资产都不影响已有成片（成片是独立图片，拍摄记录保留）。本人模特例外，见 F-05。
- 总资产为独立入口，按场景、模特、饰品、店铺参考分类浏览和管理；可查看全部成片。

**验收**
- 主线：同一用户上传 4 件饰品（其中 2 件调性相近），能让相近的 2 件**复用**同一间工作室、另 2 件**新建**不同风格的工作室；各工作室在首屏一眼区分、随时进入；复用的那间工作室在首屏显示两件饰品，两件的成片都在其中。
- 为一件新饰品选工作室时，可在「复用已有 / 新建」之间直接选择，两条路径步骤数相当。
- 在一间工作室内把模特**切换**为另一位，再拍一次，新成片使用新模特，旧成片保留。
- 新建 2 个工作室共用同一场景，把其中一个工作室的模特切换为另一位，另一个工作室不受影响。
- 修改上一条的共享场景后，两个工作室都使用新版本；修改前拍的成片不变，且能查看其拍摄时的场景版本、模特版本、饰品。
- 替换元素后已有成片数量不变；再拍一次，成片数量增加。
- 删除一个正被工作室使用的场景时被拦下并提示使用数量；从所有工作室换掉后可删除，已有成片仍可查看和导出。

### F-02 上传饰品 · P0
- 用户先选品类（项链 / 手链 / 耳饰），再上传**正面、侧面、反面三张实拍**（必传）。上传方式：拖入文件。
- 图片要求：JPG / PNG / HEIC / WebP，短边 ≥ 1000 px，单张 ≤ 20 MB；不符合时说明哪张、哪项不符合【建议，开发时确认】。
- 主尺寸必填，输入框旁附软尺测量示意图。按品类的字段：【待定：以下为建议，开工前确认】
  - 项链：链长 cm（必填）；吊坠尺寸（选填）
  - 手链：链长 / 手围 cm（必填）；主珠或吊饰尺寸（选填）
  - 耳饰：垂坠总长 cm（必填）；主体宽度（选填）
- 饰品只来源于这三张实拍；店铺参考图不参与饰品识别。
- **标准三视图**：系统把三张实拍整理为标准三视图（抠图、统一背景），展示给用户确认后存为饰品资产。整理只做抠图与统一背景，饰品像素不改（属于 F-07 保真硬规则的适用范围）。抠图边缘不理想时，用户可选择重新整理。

**验收**
- 缺任一视角或缺主尺寸时无法提交，并提示缺什么。
- 图片格式、分辨率或大小不符合要求时无法提交，并指出是哪一张、哪一项。
- 三个品类各上传一件，均能生成标准三视图并进入下一步。
- 标准三视图中的饰品与原实拍逐像素一致（背景区域除外）。

### F-03 聊作品气质与设定卡 · P0
- 输入：饰品标准三视图 + 店铺参考（选填，作辅助理解；可新上传，也可从总资产中选用，新上传的存入总资产）。以**作品气质**为主。
- Agent 最多提出 5 个问题，每个问题都提供选项（可附「其他」）。
- 匹配前展示设定卡，含两部分：**背景**（氛围、色调、材质、光线）、**模特**（气质、穿搭、动作）。用户可点「就这样」或修改任一项。设定卡各项都有值且用户确认后，才进入匹配（F-04、F-05）。
- 具体问题内容与选项：【待定】

**验收**
- 用户可以全程只点选完成本步。
- 设定卡出现前，提问不超过 5 个。
- 未确认设定卡时无法触发场景生成与模特推荐。

### F-04 生成场景（背景） · P0
- 按设定卡的背景部分，一次生成 4 张不同区域 / 角度的环境图（如主拍摄区、两个侧角度、远景氛围）。
- 用户可全部保留、删除部分、或重新生成；保存后成为一个场景，进入总资产，用户可命名。

**验收**
- 一次生成恰好 4 张；保存后的场景可在另一个工作室中选用。

### F-05 模特 · P0
- 按设定卡的模特部分，从预置模特库**推荐**匹配作品气质的模特供挑选；用户也可浏览整个预置库自选。
- 用户可经 Agent 对话描述（气质、穿搭、动作等）生成新模特，生成后存入总资产。
- **本人模特**：用户可上传本人照片生成模特。上传前须勾选「照片是我本人」声明，并单独同意人脸信息使用条款（人脸属敏感个人信息）；未同意不能上传。本人模特只在该用户账号内可见、可用。用户可随时删除本人模特，删除时原始照片与生成的模特一并删除；即使正被工作室使用也可删除，相关工作室显示「缺模特」，补选后才能再拍。条款文案【待定】。
- 已组建工作室中更换模特，即 F-01 的切换。

**验收**
- 确认设定卡后，展示按气质推荐的模特；不同气质的设定卡给出不同的推荐结果。
- 新用户在没有任何自有模特时，可直接从预置库选一位完成拍摄。
- 对话生成的模特出现在总资产中，可被其他工作室使用。
- 未勾选本人声明或未同意条款时无法上传本人照片；同意记录带用户与时间。
- 本人模特在其他用户的模特库中不可见。
- 删除被工作室使用的本人模特后，原始照片与模特均不可再访问，该工作室显示「缺模特」并阻止拍摄，直到补选。

### F-06 构图 · P0
- 点选式选择：构图（局部特写 / 半身 / 全身）、露脸（不露脸 / 侧脸 / 露脸）。AI 试戴图张数见 F-07。
- 按品类的默认值：【待定：以下为建议，开工前确认】项链 = 颈部特写 + 不露脸；手链 = 手腕特写；耳饰 = 耳部特写 + 侧脸（不露全脸）。
- 选项细节：【待定】

**验收**
- 不做任何修改直接拍摄时，按所选品类的默认构图出图。

### F-07 拍摄与套图 · P0
- 一套成片默认包含：**4 张 AI 试戴图 + 1 张实物图 + 1 张尺寸标注图**。实物图、尺寸标注图默认附带，可取消；AI 试戴图张数可调，范围【待定】。
- 实物图：默认使用标准三视图的正面图；提供「换成原始照片」选项。
- 尺寸标注图：以标准三视图正面图为底图，标注该饰品的尺寸（按品类字段）。此图不经 AI 生成。
- 画幅二选一：1:1 或 3:4。
- **饰品保真（硬规则）**：AI 试戴图中的饰品，其结构（珠子顺序、吊坠 / 主体形状、链扣位置）、颜色、比例与用户上传的实拍一致。实现路线【待定：锁定实拍像素 vs AI 参考重画，开工前与用户确认】；任何调整（含外层 Agent 的调整）都在保真规则之内进行。
- 多角度的实现方式：依赖上一条的路线，【待定】。
- **保真判定**：用户逐张「像 / 不像」（F-09）+ 内部抽查。内部抽查 = 按品类抽取 AI 试戴图，人工对照用户实拍，逐项核对结构、颜色、比例并记录结果。抽查比例与通过标准【待定】。

**验收**
- 默认一次拍摄产出 6 张图，组成如上。
- 尺寸标注图上的数字与用户填写的尺寸一致。
- 内部可按品类抽取 AI 试戴图，与对应实拍并排查看，逐项记录结构 / 颜色 / 比例是否一致，并可按品类汇总抽查通过率。

### F-08 导出与 AI 标识 · P0
- 导出：单张下载、整套打包下载。
- 输出规格：JPG；1:1 不低于 1500 × 1500 px，3:4 不低于 1500 × 2000 px【建议，开发时确认，以各平台主图要求为准】。
- 每张 AI 生成的图**默认带显式「AI 生成」角标**，且**始终写入隐式标识元数据**。
- 用户可申请导出无显式角标的版本：先展示并让用户同意责任条款（用户承担标识义务与使用责任），记录日志后提供。隐式元数据在任何导出中都保留。
- 实物图与尺寸标注图不加 AI 角标（二者饰品像素均来自实拍，只做抠图、统一背景与标注）。
- 依据：《人工智能生成合成内容标识办法》（2025-09-01 施行）。条款文案【待定】。

**验收**
- 默认导出的 AI 图可见角标，文件元数据中可读到隐式标识。
- 未同意条款时无法导出无角标版本；同意后生成一条带用户与时间的日志。

### F-09 保真反馈 · P0
- 每张 AI 试戴图下提供「像 / 不像我的饰品」。
- 点「不像」：以选项追问原因（形状 / 颜色 / 大小 / 细节），据此对该张定点重拍。P0 在页面内完成追问；F-10 上线后由外层 Agent 承接。
- 同一张连续重拍仍「不像」达到上限时，按 F-11 处理。
- 记录每次「像 / 不像」及原因，按品类可统计。

**验收**
- 点「不像」后出现带四个选项的追问；选择后该张被重拍，原图保留为历史。
- 能按品类导出「不像」次数与原因分布。

### F-10 外层 Agent · P1
- 形态：页面为主，Agent 作为全局常驻对话面板，每个页面都可唤起。
- 能力一 · **创建 / 复用工作室**：用户上传饰品后，用一句话让 Agent 调用工作流完成新建（F-03 → F-04 + F-05 → 组建，见 F-01）或复用（选定已有工作室、选中这件饰品），再进入拍摄（例：「帮这条银项链建一间清冷风的工作室」「用上次那间海边工作室拍这对耳环」）。执行中在两处停下由用户确认：**设定卡**（沿用 F-03 规则）、**保存为工作室**（沿用"写入资产需用户同意"规则；确认时一并展示将入库的场景 4 张图与模特，用户可在此替换或删减）。上传三张实拍由用户完成。
- 能力二 · **针对性调整**：用一句话调用工作流完成定点调整（例：「第 3 张吊坠改小一点」「换成海边再拍一套」）。
- 提示词：由 Agent 在后台修改，默认不展示；提供「高级」展开查看。
- 写入资产：Agent 调好的效果，先询问「要不要存进这个场景 / 模特」，用户同意后才写入资产。
- 自主边界：除上述两个固定确认点外，哪些操作直接执行、哪些先确认【待定，按具体场景与用户确认】
- 硬规则：保真规则（F-07）、隐式 AI 标识（F-08）、生成额度（F-11）对 Agent 同样生效；自动重试有次数上限，达到上限时停下并询问用户。上限数值与 F-11 的「不像」重拍上限为同一配置项，数值【待定】。

**验收**
- 上传饰品后，仅通过与 Agent 对话（加两次确认：设定卡、保存工作室）即可新建一间工作室并完成一次拍摄；结果与页面操作路径产出的工作室结构一致（场景、模特、饰品均入总资产）。
- 通过 Agent 指定一间已有工作室，可为新饰品复用并完成拍摄。
- 在任一页面输入调整指令，Agent 能完成一次对应调整并给出结果。
- 未经用户同意，场景 / 模特资产不被修改。
- 达到重试上限时，Agent 停止并向用户提问。

### F-11 生成额度与失败处理 · P0
- 每位用户实验期有 **200 张**生成额度。所有 AI 生成统一按张扣减：AI 试戴图、单张重拍、场景环境图、模特生成。实物图、尺寸标注图、标准三视图整理不扣。
- 每次生成前显示将消耗的张数和剩余额度。剩余 ≤ 20% 时提醒；用完后不能再发起生成，提示联系运营人工加额度。已有成片仍可查看和导出。人工加额度的操作方式开发时确认。
- **生成失败**（报错、超时）：告诉用户失败原因，不扣额度，可一键重试。
- **重拍仍不像**：同一张连续「不像」重拍达到上限（与 F-10 重试上限同一配置项，数值【待定】）后，停止重拍，提示「这件暂时拍不好」，并生成一条人工跟进记录（用户、饰品、品类、各次「不像」原因）。

**验收**
- 每成功生成一张，额度减一；生成失败时额度不变，且可一键重试。
- 剩余 40 张时出现提醒；额度为 0 时无法发起任何 AI 生成，已有成片仍可导出。
- 运营为某用户增加额度后，该用户可继续生成。
- 同一张「不像」重拍达到上限后不再自动重拍，出现提示，并能在后台查到对应的人工跟进记录。

## 6. 非功能与合规

- 账号：登录后才能保存资产；登录方式【待定】。
- 资产持久化：总资产与成片在用户账号下长期保存，可再次使用。
- 合规：F-08 的 AI 标识要求为硬性要求。
- 隐私：用户上传的饰品与店铺参考图仅用于该用户的生成。本人照片按敏感个人信息处理：单独同意、仅本人可用、可随时删除（F-05）。

## 7. 埋点与实验指标

用于首轮实验判定（见 `../调研/04-机会解决方案树.md`）：
- 每位用户：导出次数、成片张数；用户自报「是否已上架」及上架链接（人工收集即可）。
- 每张 AI 图：「像 / 不像」及原因，按品类统计。
- 匹配记录（主卖点信号）：每件饰品走的是复用还是新建；复用与新建时可选填原因（调性相近 / 风格不同 / 其他）；拍摄前是否切换了模特或场景。工作室数量本身不作为指标。
- 「这间工作室适合这件作品」自评：1–5 分 + 一句话原因（实验期问卷，可在产品外收集）。
- 护栏指标（实验期盯住、不应恶化）：按品类的「不像」率与内部抽查通过率；每位用户已用额度、每套成片平均消耗张数（含重拍）、生成失败率；触发人工跟进的次数。

## 8. 首轮实验的「可测门槛」

开发完成并可进入实验的条件：
1. 按品类分别判定：某一品类能稳定生成饰品与原图一致的试戴图（「不像」率阈值【待定】），该品类即可进入实验；未达标品类暂缓。
2. 用户全程无需书写提示词即可走完 `## 4` 的页面流程（Agent 路径为 P1，不作门槛）。
3. 导出带 AI 标识，套图含实物图与尺寸标注图。
4. 全部 P0 需求验收通过，含 F-11 额度与失败处理。

## 9. 待定与停车场

**开工前需与用户确认**：技术栈；生图模型供应商与备选；饰品保真实现路线与多角度方案；同一场景多张环境图之间布局 / 材质 / 光线的一致性做法；各品类尺寸字段与默认构图；F-03 问题与选项；F-06 选项细节；AI 试戴图张数范围（F-07）；内部抽查比例与通过标准（F-07）；Agent 自主边界；重试 / 「不像」重拍上限（F-10、F-11 共用）；「不像」率阈值；登录方式；F-08 条款文案；本人模特条款文案（F-05）；上传与输出规格的建议值（F-02、F-08）；人工加额度方式（F-11）；删除工作室时其成片如何处理；用户中途未保存时，已生成内容如何保留与恢复。

**停车场（首版不做）**：全店风格统一模板、创作节奏优化、手机端、跨境与 Etsy、一键发布、收费方式（实验后定）。
