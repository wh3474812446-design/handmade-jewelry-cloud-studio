# 手作饰品云工作室｜产品方案（合伙人 / 投资人对齐版）

版本：v0.2（2026-10-28）  
状态：调研与产品定义完成，尚未开发。本文判断均标注依据；"推断"为分析结论，"待验证"为首轮实验要回答的问题。

---

## 一、每件手作，都该有一间合它气质的工作室

**每一件手作都是独一无二的，它的风格也各不相同。**

一条森系的木珠手链，适合窗边的木桌和午后的光；一对清冷的银耳坠，适合灰墙和冷调的侧光；一条复古的珍珠项链，也许该在海边被拍下。

但今天的手作人，往往只有一张桌子、一盏台灯、一部手机。所有作品挤在同一个背景、同一种光线里拍——作品的气质，在照片里被抹平了。

**手作饰品云工作室，为不同风格的作品，配上不同风格的工作室。** 读懂一件作品的气质，按它匹配背景和模特，组建一间最合适的工作室，拍出饰品原样不改、可以直接上架的试戴套图。

调性相近的作品，复用同一间工作室就好；风格不同，就换一间或新建一间。用哪一间，看作品而定。

## 二、为什么这是一个真问题

**手作人做得出独一无二的作品，却给不了它独一无二的拍摄环境。**

- **没有工作室、没有模特**：卖家原话"之前为了拍耳饰佩戴图，找模特、搭场景、调光线，折腾大半天还不满意"；新手求助"这个图片的背景色怎么搭建或者用软件弄出来"。抖音上已形成成熟的"不露脸饰品模特"兼职生态（二手报价约 10–18 元 / 张）。
- **自己拍门槛高**：一篇饰品拍摄教程获 9299 赞，评论却是"跟着教程都拍不好""拍出来像是从垃圾堆里摸出来的一样"。
- **饰品要拍"状态"，不只是拍东西**：手作圈的高频经验是《做饰品，你不要拍饰品，要拍状态》；Etsy 饰品视觉从业者也提醒，先想清楚"这套图最后想让人记住什么"。
- **用 AI 又会"改掉"饰品**：卖家原话"生成产品图以后，图片和产品完全两模两样"；买家投诉"实物很小却 AI 很大"。

> 依据：`../调研/03-用户声音.md`（小红书、抖音、B 站公开内容，含原文链接）
> 如实说明：前两点证据充分；"不同作品需要不同风格环境"有间接支持、卖家直接表述较少，列为首轮实验的重点观察项（见第七节）。

## 三、为什么是现在

1. **生图能力已经够用，但没人为"每件手作"去做**：通用模型出图成本已降到几分钱一张，但它们面向所有人、所有商品；手作人得自己学提示词，还会碰到饰品尺寸失控、细节变形。
2. **监管与平台把"真实"变成硬要求**：《人工智能生成合成内容标识办法》2025-09-01 施行；淘宝 2026-07 专项治理"AI 批量套图"；买家态度是"把 AI 图当效果展示图我还可以忍，为什么现在连实物图都没有了"。**推断**：能做到"饰品真实 + 实物图并存 + 合规标识"的垂类工具，商家才敢用。

> 依据：`../调研/01-市场格局.md`

## 四、我们服务谁

- **谁**：自己设计、制作项链、手链、耳饰，但没有拍摄条件、也不会拍的手作饰品人。
- **在哪**：淘宝、小红书、抖音、闲鱼等国内平台。
- **不是谁**：已有拍摄能力的商家；义乌 / 广州批量外包拍摄的大 SKU 商家。

## 五、和别人有什么不同

| | 美图设计室 | WeShop 唯象 | 通用生图模型 | **手作饰品云工作室** |
|---|---|---|---|---|
| 出发点 | 全能设计工具，Agent 一句话出电商套图 | 服装 AI 商拍 → 模型聚合 | 通用生图 | **每件手作独一无二** |
| 对"作品气质"的处理 | 通用模板与 Agent | 「固定场景」：同一场景反复用 | 靠用户写提示词 | **读懂每件作品的气质，匹配合适的工作室：相近复用、不同新建，模特与场景随时切换** |
| 饰品专用能力 | 无（AI 模特页按服装设计） | 无（用户问"饰品能用嘛？"无回复） | 无 | **项链 / 手链 / 耳饰专用流程** |
| 主要短板 | 计费口碑差（"积分消耗特别猛""月底清零"） | 饰品人群几乎无渗透 | 饰品尺寸 / 细节失控 | 尚未上线 |

**打法（已拍板）**：做垂类场景产品。同样的出图效果大厂也能做到；我们赢在"懂手作"——懂每件作品不一样，并把"为它配一间合适的工作室"做到最顺手。

> 依据：`../调研/02-竞品快照.md`、`../调研/05-定位陈述.md`

## 六、产品怎么做到（功能服务于主线）

**主线体验**：上传一件作品（正、侧、反三张实拍，系统整理成标准三视图）→ 调性和已有工作室相近，就复用、直接拍；风格不同，就新建：和 Agent 聊它的气质 → 按气质匹配背景（生成 4 张环境图）和模特 → 组建工作室 → 选构图，出一套试戴图 → 下载上架。工作室之后可以调整，也可以给调性相近的作品复用。

**支撑主线的功能**：
- **多工作室**：场景、模特、饰品、店铺参考都是用户的资产；调性相近的作品复用同一间，风格不同就新建；工作室里的模特、场景随时可以切换。模特可从预置库挑、对话生成，也可以用卖家本人的照片（单独授权、只自己可用）。
- **读懂作品气质**：Agent 用选项提问，不用写提示词；匹配前给出设定卡（背景：氛围、色调、材质、光线；模特：气质、穿搭、动作）供确认。
- **饰品原样不改**：上传正、侧、反三张实拍与尺寸，系统只做抠图和统一背景，整理成标准三视图；成片里饰品结构、颜色、比例与实物一致。
- **让买家信**：每套图默认附实物图与尺寸标注图（饰品来自实拍，不经 AI 生成）；默认 AI 合规标识。
- **一句话交给 Agent**：上传饰品后，可以直接对全局常驻的 Agent 说"帮这条银项链建一间清冷风的工作室"或"用上次那间海边工作室拍这对耳环"，由它调用工作流完成创建或复用，关键处（设定卡、保存工作室）请你确认。Agent 排在页面核心流程跑通之后上线。
- **哪里不好改哪里**：同一个 Agent 可定点调整；用户点"不像我的饰品"后追问原因并重拍。

**首版范围**：项链、手链、耳饰；电脑浏览器网站；中文、国内平台；实验期免费（每人 200 张生成额度，控制成本）；只做下载导出。

> 完整需求见 `PRD-编码Agent版.md`；决策记录见 `../调研/06-决策日志.md`。

## 七、怎么验证

- **目标**：10 位目标用户中 **≥5 位把成片真实上架使用**，且 0 例因饰品失真被投诉或撤下。
- **主卖点观察（看匹配度，不看工作室数量）**："这间工作室适合这件作品"自评（1–5 分）；每次复用或新建工作室的原因。作品调性相近时只用一间工作室属正常。
- **同时记录**：按品类的"不像我的饰品"比例与原因。
- **失败信号**：<3/10 上架，或出现失真投诉 → 优先攻饰品保真；若上架达标但"工作室适合这件作品"自评普遍偏低，或用户反映风格不同的作品也只能挤在同一间里拍 → 重新审视主卖点的实现。
- **招募与节奏**：先熟人、再公开招募，三个品类尽量都覆盖；先做出工具，再跑实验。

> 依据：`../调研/04-机会解决方案树.md`

## 八、主要风险（如实列出）

| 风险 | 说明 | 应对 |
|---|---|---|
| 主卖点需求待验证 | "不同作品配不同风格环境"在卖家原话中直接表述少 | 首轮实验观察"工作室适合这件作品"的匹配度自评，以及每次复用 / 新建的原因 |
| 饰品保真做不到 | 用户敢不敢上架的前提，技术上最难 | 按品类分别验收，未达标品类暂缓；技术路线开发时专门评估 |
| 手作信任 | 买家本就在"识图验真"（相关讨论 637 条评论），AI 图可能被视为"不真手作" | 默认附实物图、尺寸图与 AI 标识；实验中观察买家反应 |
| 护城河偏薄 | WeShop 有固定场景 + 专属模特；通用模型保真在提升 | 壁垒放在"读懂手作饰品气质"的提问、默认值与场景库 |
| 价格锚点低 | 同货架有 ¥30 / 月的美图与几分钱一张的通用模型 | 实验期免费，先验证"能用、爱用"，计价实验后定 |
| 样本小 | 首轮 10 人分三个品类 | 按品类记录，必要时追加样本 |

## 九、需要对齐的事项

1. 是否认同"每件手作独一无二 → 用不同风格的工作室适配不同饰品"作为产品故事与主打卖点。
2. 首轮实验目标（≥5/10 真实上架）及主卖点观察项，是否作为继续投入的判断依据。
3. 收费方式在实验后决定（初步原则：避免"月底清零的积分"这类引发反感的计费）。
