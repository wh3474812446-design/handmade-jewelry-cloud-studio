# 审美方向（taste skill · 2026-10-28）

需求：`PRD/PRD-编码Agent版.md` v0.3。本文件只定审美方向，交给 impeccable 落地。

## 风格
- `framed-sheet`（seed 1548309252，kind builder，light），完整 sheet 见 `direction.json`（`draw.mjs --show`）。
- 为什么：上新是一次 20–40 分钟、在电脑上连续完成的工作（上传 → 气质 → 组建 → 拍摄 → 挑图）。浅色框架退后，作品放在一张白纸面上，正好像摄影棚里的无缝背景纸。旧原型用的 accent-ladder 不再沿用。
- 没有 redraw。

## 面孔（face）
- 外框色从手作工作台取：低彩度石灰 `#f4f3ef` 代替 `#f9fbfc`；白纸面不变。
- 品牌色 = 铜绿 `#1b6c80`（银、铜饰品氧化后的颜色；就是 sheet 发的 teal），只用在主数据元素和一个选中态：额度进度、当前选中的成片、「像」的计数。
- 字体：IBM Plex Sans（拉丁与数字）+ 系统中文黑体（PingFang SC / Noto Sans SC）。Plex Mono 只用于尺寸数值（cm），是唯一的第二字体任务。

## 招牌元素（只有这个产品有）
**珠序对照条**：每件饰品由一串固定的珠子 / 吊坠描述（颜色、顺序、形状）。同一份图形在三处出现：实拍、标准三视图、每张 AI 成片。每张成片下有一条细细的珠序条，和实拍的珠序并排，「像 / 不像」就在旁边。保真不靠文字声明，在屏幕上就能核对。

> 在这个原型里，**饰品的珠序**变成**每张成片下的对照条**。

## 图像
- 开放图库（Openverse / Wikimedia）连续超时、503，拿不到可靠图片；而且用别人的饰品照片冒充 AI 成片，会和保真卖点冲突。
- 因此全部用代码绘制，一套统一的平面语言：
  - 饰品：SVG，按数据里的珠序绘制，三处共用一份。
  - 场景：大块平涂色场（背景纸、桌面、窗光矩形、海平线），4 张环境图 = 同一场景的四个机位。
  - 模特：只画局部特写的肤色轮廓（颈肩 / 手腕 / 耳侧），不画五官，与默认构图一致。
- 所有图都是示例，界面上不写"此图为示意"之类的说明，在使用说明里交代。

## 每屏的一个问题
| 屏 | 问题 | 最大的东西 | 主要动作 |
|---|---|---|---|
| 我的工作室（首页） | 这件新作品该进哪间工作室？ | 工作室列表（场景 + 模特 + 拍过的饰品） | 上新一件作品（近黑主按钮） |
| 上新（builder） | 这件作品是什么气质、配哪间？ | 当前步骤的工作区：三视图 → 复用 / 新建 → 设定卡 → 4 张场景 → 模特 | 每步一个「下一步」 |
| 工作室（detail） | 这一套能不能直接上架？ | 成片印样：4 AI + 实物 + 尺寸图，带珠序对照与像 / 不像 | 拍一套（显示消耗张数） |
| 总资产（list） | 我有哪些素材、被谁在用？ | 按场景 / 模特 / 饰品 / 店铺参考 / 成片分 tab 的列表，「被 N 间工作室使用」 | 上传 / 删除（被使用时拦下） |

## 规则提醒（app-screens 规则）
- 颜色 < 3%，只在数据上；主按钮近黑。无渐变、无阴影（只有浮层有）、无图标色块、无 emoji、无小号大写标签、无 01/02 编号。
- 标题 22px / 600；数字 tabular-nums；正文 14px；最小 12px。
- 一个 gap（24px）；卡片 8px 圆角、控件 6px、纸面 16px。
- 手机：外框消失，纸面就是屏幕，48px 顶栏（菜单、标题、一个动作）。
- 示例数据写成一个数据文件，额度等总数从行计算，并用 console.assert 校验。
