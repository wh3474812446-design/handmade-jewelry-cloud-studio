# 在 claude.ai 生成 Artifact

## 步骤

1. 打开 claude.ai，新建一个对话。模型选最新的 Opus 或 Sonnet，因为要一次输出约 3.5 万 token。
2. 上传同目录的 `云工作室原型-artifact.html`。
3. 粘贴下面这段提示词，发送。
4. 生成完成后，在 Artifact 里点几下，确认能用：首页、进入工作室、助手面板、侧栏底部的「切换到新用户」。
5. 是否「发布 / 分享」由你决定。默认只有你自己能看到。

## 提示词（整段复制）

```
请把我上传的 HTML 文件原样做成一个 HTML Artifact（类型 text/html）。

要求：
1. 逐字保留文件内容，不要改写、删减、重构、"优化"任何代码或文案，也不要把它改成 React。
2. 这是一个可点击的产品原型，所有图都是内联 SVG，没有外部依赖，可以直接运行。
3. 如果一次输出不完，就在中断处继续接着输出，直到 </html>，不要从头重写。
4. 输出完成后只回复一句"已生成"，不需要解释代码。
```

## 如果生成失败

- **输出被截断、页面空白**：让它「从中断的那一行继续」。如果还是不行，回到 Claude Code 跟我说，我再把文件拆成更小的版本。
- **它改动了代码，或者页面和本地不一样**：以本地的 `原型-临时/云工作室原型.html` 为准，让它重新原样输出。
- 这个文件由 `原型-临时/src/` 合并、压缩而来，改了源码后需要重新生成这个版本。
