> - 饰品输入：必须上传正面、侧面、反面三张实拍 + 按品类填写主尺寸；系统据此整理出标准三视图（只抠图、统一背景，饰品不改）；店铺参考图只用于辅助理解气质，**不再从中识别 / 提取饰品**（第 4 节第一步「两类素材均支持提取三视图」已调整）。
> - 主流程：上传实拍整理三视图 → 聊作品气质 → 按气质匹配背景与模特 → 与三视图一起组建工作室 → 选构图拍套图；工作室可复用（调性相近的作品直接复用拍摄），工作室内可切换模特、场景、饰品。
> - **主打卖点（产品故事）**：每件手作都独一无二、风格各不相同，所以需要不同风格的工作室去适配不同的饰品；调性相近的作品复用同一间工作室，视具体作品而定；其余都是支撑这一卖点的功能。
> - 工作室：可以是任意场景（如海边），不绑定模特；模特为独立数字人资产；用户可建多个工作室，按作品气质复用或切换。
> - 构图（局部试戴 / 完整人物）：由用户按需点选，不固定。
> - 新增外层常驻 Agent，可调用工作流：直接创建 / 复用工作室（与页面操作并列的入口），以及做针对性调整。
> - 首版为电脑浏览器网站、中文、国内平台、需登录、实验期免费、仅下载导出。

## 1. 产品定位

面向手作饰品创作者和小型饰品商家的 AI 商品图产品。通过 Agent 与用户逐步交互，确认符合店铺和作品气质的工作室环境、模特风格，生成不同角度的试戴套图，并允许保存和复用流程中的每一步资产。

核心构思：为没有精心布置的工作室的商家，提供搭建自己的商品图环境、生成商品试戴套图的平台。

## 2. 目标用户与需求来源

### 目标用户

- 自己设计、制作项链、手链、耳饰等作品的手作创作者。
- 缺少模特、摄影空间或商品拍摄能力的小型饰品商家。

### 聊天中提出的痛点

- 创作者会制作饰品，但拍不出满意的商品图，尤其缺少模特试戴图。
- 消费者只有单品图时，难以判断实际佩戴效果，购买时容易犹豫。
- 图片风格需要适配饰品与店铺，商家希望沉淀并延续自己的视觉风格。
- 手作产品可能产量低、构思时间长，拍摄方式需要适应这类创作节奏。

上述信息来自个体经历与讨论，目前尚未验证需求普遍性、使用频率和付费意愿。

## 3. 已确认的产品方向

1. 聚焦手作饰品场景，页面引导与流程围绕该场景设计。
2. 根据店铺和手作产品的性格、情绪，设计背景空间以及模特穿着风格和动作。
3. 环境与模特设定通过 Agent 和用户交互、文字确认后推进。
4. 环境阶段生成多张背景图，模拟整个工作室环境；
5. 用户可以选择是否保存工作室环境并复用。
6. 最终生成不同角度的试戴套图。
7. 中间每一步产生的资产都需要支持保存。

## 4. 当前确认的产品流程

### 第一步：上传参考与饰品，建立初始资产

- 上传店铺参考和饰品照片。
- 两类上传素材均支持从中识别饰品、提取饰品三视图。
- 店铺参考可以保存，作为后续环境与风格确认的依据。

可保存资产：店铺参考、饰品原始照片、饰品三视图。

注意：这里的「提取」是产品目标，不代表任何输入照片都能提供真实完整的三视图。缺失视角的处理方式仍待确认。

### 第二步：Agent 交互确认环境与背景氛围

- Agent 结合店铺参考和饰品，与用户通过文字交互。
- 确认环境背景图的氛围，涉及店铺与作品的性格、情绪，以及空间、色彩、材质和光线等表达。
- Agent 判断当前信息是否足以推进，并通过文字向用户确认。

可保存资产：环境氛围描述、已确认的环境设定。

### 第三步：生成多张工作室环境背景图

- 根据已确认的环境氛围生成多张背景图，模拟整个工作室环境。
- 用户选择是否保存该环境，供后续复用。

可保存资产：各张环境背景图、工作室环境及其关联设定。

### 第四步：Agent 交互确认试戴模特风格

- Agent 与用户通过文字交互，确认试戴模特的风格。
- 结合前序构思，确认内容涵盖人物气质、穿着风格与动作；具体字段和交互细节待设计。
- Agent 判断信息是否足够，并通过文字确认后推进。

可保存资产：模特风格描述、穿搭与动作等已确认设定。若后续产生模特预览图，也应支持保存；是否设置独立预览步骤尚未确认。

### 第五步：生成不同角度的试戴套图

- 组合饰品资产、工作室环境和模特风格设定。
- 生成不同角度的试戴套图。

可保存资产：单张试戴图、整套试戴图，以及关联的生成设定。

## 5. 资产保存与复用要求

**已确认：每一步的资产都需要能够保存；环境可以由用户选择保存复用。**

| 资产类别 | 内容 | 用途 |
|---|---|---|
| 店铺参考 | 用户上传的店铺视觉参考 | 后续风格讨论与环境设计依据 |
| 饰品素材 | 原始照片、三视图 | 饰品展示与多角度生成依据 |
| 环境设定 | 已确认的氛围与空间描述 | 保存用户确认过的拍摄意图 |
| 工作室环境 | 多张环境背景图及关联设定 | 后续拍摄复用 |
| 模特设定 | 人物风格、穿搭、动作等 | 后续试戴生成依据 |
| 成片 | 单张图片、多角度套图 | 商品展示与导出 |

补充建议，尚未拍板：支持从已保存资产继续流程，例如沿用环境更换饰品；同时保存成片与所用素材、设定的关联，便于再次生成和修改。保存的入口、默认行为、版本管理与资产组织方式尚待设计。

## 6. 产品应体现的价值

- 降低缺少摄影资源的商家制作试戴图的门槛。
- 让空间、模特穿搭与动作围绕饰品及店铺气质形成协调表达。
- 通过保存与复用，减少新品重复确认拍摄风格的工作。
- 用多角度试戴图帮助消费者理解佩戴效果。

这些是预期价值，尚不能作为已验证的产品效果。

## 7. 待确认事项与质量风险

以下内容在讨论中被提出，但尚未形成最终需求或实现决策。

### 饰品真实性与三视图

- 店铺参考图中包含多件饰品时，如何让用户选择目标？【已定：不再从店铺参考图提取饰品，问题消失】
- 原图缺少侧面或背面时，是要求补拍，还是允许 AI 推测补全并标记？【已定：正 / 侧 / 反三张实拍必传】
- 饰品尺寸、珠子排列、吊坠结构、链条、材质与颜色如何核对？【已定：用户"像 / 不像"+ 内部结构 / 颜色 / 比例抽查，见 PRD F-09】
- 佩戴比例需要用户提供哪些尺寸信息？【已定：按品类主尺寸必填，见 PRD F-02】

### 工作室环境一致性

- 多张环境图分别覆盖哪些视角、区域或构图？【已定：每次 4 张，主拍摄区 + 两个侧角度 + 远景氛围】
- 同一工作室在不同视角下的布局、材质与光线如何保持一致？【未定：属技术实现，开发时处理】
- 用户不保存环境时，当前任务的生成结果如何保留和恢复？【未定：已列入 PRD 第 9 节待定项】

### 模特与套图

- 首版支持哪些饰品品类？耳饰、项链和手链均被讨论到，但没有确定首发范围。【2026-10-28 已定：项链、手链、耳饰，见 `PRD/PRD-编码Agent版.md`】
- 采用局部试戴还是完整人物？之前的项链参考以颈部局部试戴为主，尚未确定产品范围。【2026-10-28 已定：由用户按需点选，见 PRD F-06】
- 模特是否需要独立预览、身份复用，以及与环境绑定？【已定：模特为独立资产，可复用，不绑定环境】
- 套图的角度、数量和画幅如何确定？【已定：4 AI 试戴 + 1 实物图 + 1 尺寸标注图；1:1 或 3:4；角度随构图点选】

### Agent 交互与流程控制

- 什么信息达到「足够确认」？用户如何表达最终确认？【已定：设定卡各项有值 + 用户点确认】
- 哪些内容可由 Agent 推断，哪些必须向用户追问？【部分已定：设定卡、保存工作室为固定确认点；其余自主边界开发时定】
- 修改前序设定后，哪些后续结果需要重新生成？【已定：已有成片保留为历史，不自动重拍】
- 生成失败、饰品变形或风格不符时，如何反馈和重做？【已定：「不像我的饰品」→ Agent 追问原因 → 定点重拍】

### 商业与实现边界

- 商家实际使用频率、可接受价格与付费方式未验证。
- 技术栈、模型、架构、数据模型和部署方式均未确定。
- 「云工作室」目前描述可复用的视觉环境，不代表已经决定建设可交互的三维空间。

## 8. 建议的下一步验证（未拍板）

> 【2026-10-28】已被 `调研/04-机会解决方案树.md` 的实验设计取代（先做出工具，再招募 10 位目标用户真实试用）。

用真实手作饰品与店铺参考，人工辅助走完一次完整流程：确认环境氛围、生成环境、确认模特风格、生成多角度套图，再用另一件新品测试环境复用。

建议重点观察：

- 创作者是否认可环境与模特表达了店铺和作品的气质。
- 成片是否保留饰品细节与合理的佩戴比例。
- 多张环境图和套图是否保持一致。
- 用户是否愿意将成片实际用于商品展示。
- 保存的资产能否在下一次创作中减少重复操作。

具体验收阈值、验证样本与首版范围待后续确认。
